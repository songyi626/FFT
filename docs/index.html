FFT 與 SAED 的差異

HRTEM 影像的 FFT 是影像強度的傅立葉轉換，不是電子繞射圖。亮點的位置可以用來判斷晶面間距、晶面夾角、對稱性與帶軸；亮點的強度則受物鏡 CTF、defocus 與樣品厚度調制，不能定量，影像的非線性還可能產生看起來像禁制反射的交叉項。可見的最高頻受顯微鏡 information limit 限制，而且 FFT 只反映 ROI 內的局部結構。報告中建議稱為 FFT pattern 或 diffractogram。

定義

k 為空間頻率（cycles / nm，不含 2π），d = 1 / |k|。頻域解析度 Δk = 1 / (N · nm_per_px)，N 為 ROI 邊長；最小可解析 d 為 2 · nm_per_px。FFT 中 kᵧ 向上為正，方位角由 +kₓ 逆時針計算。處理流程：ROI → 高斯背景扣除 → 窗函數 → 2D FFT，與 GitHub 上的 Python 桌面版相同。
